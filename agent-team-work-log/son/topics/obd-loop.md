## 2026-07-19 입력
- 주제: 디자이너 관점의 코딩 에이전트 위임/컨펌 UX.
- Chris님 관점:
  - 디자이너는 코드 전문성이 낮기 때문에 코딩 에이전트에는 최대한 위임하고, 본인은 디자인 작업을 계속하다가 구현 완료 후 결과를 보고 수정하는 흐름이 적합하다.
  - 실제 컨펌 단계는 코딩 일반보다 디자이너가 전문 판단을 할 수 있는 디자인 자동화 영역에서 더 가치가 있다.
- OBD 해석:
  - AI가 사용자에게 확인을 요청해야 하는 기준은 “작업 중요도”만이 아니라 “사용자가 그 판단에 전문성을 갖고 있는가”여야 한다.
  - 코딩형 에이전트 UX: 최대 위임 → 완료 후 시각/동작 결과 리뷰 → 수정 요청.
  - 디자인 자동화형 에이전트 UX: 방향/선택지/브랜드 판단 지점에서 중간 컨펌.
  - 혼합형 에이전트 UX: 디자인 결정은 사용자 컨펌, 구현 세부사항은 에이전트 위임.
- 비즈니스/조직 가치:
  - 디자이너의 흐름 방해를 줄이고 병렬 작업 시간을 확보한다.
  - 에이전트 컨펌 비용을 줄이며, 사람의 전문 판단이 필요한 지점에만 의사결정 에너지를 집중시킨다.
  - “AI가 언제 나타나고 언제 물러나는가”를 제품 차별화와 신뢰 설계의 기준으로 만들 수 있다.

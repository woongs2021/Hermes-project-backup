# Chris Archive session taxonomy — 2026-09 intake

Use this as a condensed reference when continuing Chris Archive work. It captures reusable class-level learning from a long Telegram image-intake session, not a one-off task log.

## Workflow lessons

- For Telegram archive intake, if Chris says `추가해줘`, proceed without further confirmation.
- Work quietly during straightforward archive intake. Avoid repeated progress fragments between tool calls; Chris noticed this as “말을 하다말어”. Send one concise completion reply after verifying the asset and entry exist.
- When adding many images in one session, use a single scripted tool flow where possible: compute KST date, copy original with slug + sha12, write entry, append index, update `DESIGN_SYSTEM_DRAFT.md`, and print verification JSON.
- Keep Chris-facing replies short: saved paths, index/draft update confirmation, 3–6 strongest design-DNA signals, and one caution when relevant.
- Mark most new entries `goyj_review_needed`; do not promote to final rules until repeated patterns, GoYJ review, or Chris approval.

## Reusable archive clusters observed

Treat these as candidate clusters, not final design-system rules.

### Ambient / companion AI
- Handheld AI companion: human hand/phone anchor, warm oval context halo, floating task/memory/status cards.
- Privacy-sensitive personal-state cards must include consent, correction, mute/delete, and non-surveillance framing.
- Useful language: `ambient companion OS`, `AI around the hand`, `context halo`, `privacy-safe emotional intelligence`.

### Light / boundary / presence
- White or pastel orb forms can signal calm AI presence, idle/loading states, or safe interface boundaries.
- Important differentiators: rim thickness, center emptiness, chromatic edge balance, beige/light backgrounds, low-intensity variants.
- Useful language: `calm luminous boundary`, `safe AI presence`, `edge as signal`, `light-theme gentle AI aura`.

### Loop / orbit / feedback
- Helix, orbit, vertical energy cores, stacked cushions, and node constellations map well to Hermes/OBD loop and feedback metaphors.
- Guard against heat/alarm/cosmic-generic readings with restrained orange/black, controlled glow, and clear loop/feedback framing.
- Useful language: `looped warm intelligence core`, `feedback orbit`, `orbital agent constellation`, `layered context resonance`.

### Mesh / emotional fields
- Mesh/halftone orbs and warm emotional fields can express relational context, protected inner voids, and human-system blending.
- Differentiate from generic gradient spheres through mesh density, transparency, shadow ratio, overlap geometry, and privacy-safe metaphor.
- Useful language: `soft relational intelligence`, `warm emotional mesh`, `protected emotional orbit`, `woven signal ecosystem`.

### Product/component grammar
- Dot-matrix AI processing, glass capsule progress bars, progress dots, pause/stop controls, and honest status labels are strong product-level references.
- Always flag progress semantics: avoid fake precision; use determinate labels when possible and accessible contrast/labels.
- Useful language: `calm AI processing UI`, `user-controllable automation`, `calm AI state component`, `progress without pressure`.

### Navigation / archive UX
- Circular content cards, biomorphic nodes, lens masks, thumb-safe control clusters, and `Explore` pills support future One UI / archive browsing studies.
- Needs usability/accessibility checks before promotion: target size, thumb reach, contrast, state clarity, information density.
- Useful language: `human-scale circular navigation`, `thumb-safe interaction field`, `biomorphic circular content system`, `UI as observation board`.

### Design-system / narrative / physical brand
- Token boards, bento specimen cards, story-card product narratives, and physical merch/label systems connect visual DNA to `DESIGN_SYSTEM.md` and brand assets.
- Extract modular label, tab, badge, card/specimen, and presentation structures rather than literal third-party phrases.
- Useful language: `living design-system board`, `story-based product OS`, `physical design-system carrier`, `modular word-label system`.

### Campaign / identity / motion
- Oversized manifesto type, chrome overlays, purple monochrome identity fields, phase-shift pattern grids, and motion-principle boards are mostly campaign/support layers.
- Third-party names/logos/phrases must be excluded; extract structure, color/material relationship, motion principle, and layout tension only.
- Mobility/cockpit references require safety, glanceability, brightness, motion speed, and distraction review.

## Entry-writing reminders

Each entry should include: short description, visible content, tags, color, typography, texture/material, layout/composition, metaphor/system meaning, product/UX implications, aesthetic score, Karina interpretation, GoYJ review request, and extraction candidates.

When the image has no text, explicitly write `none / not applicable` under typography. When third-party marks or UI are visible, add `brand_safety` frontmatter and a caution to extract principles only.

## Core theme
- **기억을 쌓는 것이 아니라 조절하는 전략 지도**.
- 전략디자인은 조직 의사결정의 언어, AI 시대 교육은 판단/검증/협업 역량, 에이전트 메모리는 축적보다 편집·망각·편향 관리의 UX 거버넌스로 연결된다.

## woongdesignv2 principles used
- Warm off-white canvas `#FCFCFF`, ink `#010102`, restrained cool/warm color planes.
- Samsung Sharp Sans / Pretendard-like hierarchy; light display weight, bold only as rare emphasis.
- Hairline stroke, 28px rounded tiles, 32px internal padding, 56px outer margin rhythm.
- No emoji, no illustration, no shadow; depth from surface/color planes and whitespace.
- Cool Blue family for information/data slides; dark charcoal/ink mode for cover and finish.
- Tactile print/paper grain and editorial material composition to reduce generated-image feel.

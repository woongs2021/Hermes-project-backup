# Chris Archive mockup-ready visual metaphor surfaces

Use when Chris says generated Chris Archive / Design DNA candidates are too close to their references, too much like old GoYJ defaults, or too much like named object metaphors, and asks for material that can be applied to mockups.

## Session learning

In the 2026-10-02 Chris Archive loop, a five-candidate run used actual image references and the outputs looked too similar to the source images. Chris corrected the workflow: the archive should be a visual reference, not a template. Later, when generated candidates became named metaphors such as protective veil / memory strata / signal garden, Chris clarified that he wanted **visual metaphor surfaces for mockups**, not specific metaphor objects.

Durable lesson: for this class of work, translate Chris Archive into **mockup-ready graphic skins**. The output should make a package, card, phone background, label, or hero surface feel meaningful when applied, without becoming a poster, UI screenshot, object icon, or narrative concept art.

## Workflow

1. Do not pass the latest archive images as `--image-references` when Chris says the prior results were too similar or copied the reference. Use archive entries, manifest metadata, or synthesis notes as hidden visual DNA instead.
2. Extract principles, not forms:
   - color tension
   - material feel
   - density / rhythm
   - crop behavior
   - negative-space logic
   - tactile print / optical mood
   - restrained signal color
3. Generate **surfaces**, not objects:
   - mockup skin
   - package panel
   - label/card background
   - mobile UI background
   - repeatable wrap
   - masked hero surface
4. Avoid both direct reference families and old defaults:
   - no poster reconstruction
   - no helix / orb / sun / phone UI / dashboard
   - no named metaphor objects unless Chris explicitly requests them
   - no warm-gray capsule default, circle seal, contour/orbit line default, diagnostic mesh default
5. Make candidates visibly different by surface family, not by color tweak.
6. Keep outputs temporary unless Chris explicitly says `저장해줘`.

## Prompt pattern

```text
Create an original 1:1 square GPT Image 2.5 graphic surface for Chris Park's Design DNA.
This is NOT a named object metaphor and NOT a finished poster.
It is a mockup-ready visual metaphor surface: a graphic skin that can be applied to package mockups, mobile UI backgrounds, cards, labels, and brand assets.
Use the latest Chris Archive as hidden visual DNA only: [principles].
Do not directly copy any Chris Archive image.
No poster, no helix, no glass orb pair, no neon landscape, no phone UI, no dashboard, no literal metaphor object.
Must be crop-friendly, mask-friendly, overlay-friendly, and repeat/placement-ready.
```

Strong negative tail:

```text
No text, letters, numbers, logo, watermark, poster headline, exhibition layout, phone UI, dashboard, fake interface, product mockup, app icon, people, photograph, literal object, helix, orb pair, red sun landscape, code screen, readable symbols, route map, orbit-line default, capsule-grid default, circle-seal default, generic AI startup neon, glassmorphism cliché, glossy 3D render, clutter, exact reference copy.
```

## Useful candidate families

- **Low-noise editorial signal skin**: tactile paper fields, black/charcoal softened surface planes, tiny restrained coral signal pressure, vellum overlays.
- **Chromatic compression surface**: warm/cool optical color pressure, compressed bands, controlled saturation, deep calm areas; suited for digital/mobile hero surfaces.
- **Raster fabric intelligence field**: data density humanized as woven raster / textile / print material; suited for package wrap or subtle UI texture.

## QA checklist

- [ ] Does it look like a surface to apply to a mockup, not a standalone artwork?
- [ ] Does it avoid literal archive forms and named object metaphors?
- [ ] Is there no readable text/logo/UI/product mockup?
- [ ] Can it crop, mask, repeat, or sit behind content?
- [ ] Are the candidates different by surface logic, not just palette?
- [ ] Is Chris Archive DNA present as taste/material/rhythm rather than copied composition?

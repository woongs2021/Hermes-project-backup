# Avoiding duplicate market-research loops

Use when running or revising Chris's Yuna / GoYJ / Karina market, AI, UX, or design-reference research loops.

## User signal

Chris noticed that some market-research loop outputs felt repetitive or overlapped with previous reports. The fix is not merely “find more news”; change the lens and source class.

## Anti-duplication pattern

Before writing a new loop output:

1. **Name the lens for this run.** Examples: product/service references, visual systems, organizational moves, user emotion/culture signals, non-AI analogies, investment/business model, interface behavior, education/workflow implications.
2. **Avoid reusing the previous dominant frame.** If the last report focused on AI trend/news summaries, switch to concrete references, edge cases, visual benchmarks, or non-obvious adjacent industries.
3. **State what is new.** Include a small “new angle today” line so the user can see why this is not the same report again.
4. **Use reference diversity.** Mix at least two source classes when possible: product launches, design portfolios, academic/industry papers, startup moves, cultural artifacts, patents, standards, physical retail/exhibition, non-AI tools.
5. **Translate to Chris’s work.** Close with implications for future One UI, Design DNA, AI UX, brand system, or Samsung MX design leadership—whichever matches the loop.

## Loop role split

- **Yuna:** AI/AX technology, products, models, agent frameworks, startup/business signals, papers; must avoid generic “AI is changing work” repetition.
- **GoYJ:** UX/design references, visual systems, IA/patterns, emotional/brand cues, non-digital or non-AI analogies that can inspire AI UX; must avoid generic moodboard trend language.
- **Karina:** final synthesis and prioritization; should resolve overlap and recommend a single useful angle rather than forwarding parallel summaries.

## Output check

If the report could have been sent last week with only names/dates changed, it is too generic. Reframe around a new lens before sending.

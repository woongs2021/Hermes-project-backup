# Chris Archive → Design DNA tab reconstruction pattern

Use when Chris asks to move beyond archive intake/doc viewing into a webapp Design DNA operating surface.

## Trigger

- Chris asks to compress `헤르메스디자인시스템.md` clusters after the first synthesis.
- Chris asks for an actual brand-asset generation prompt package.
- Chris asks to reorganize the `Design DNA` tab and explain what the `Chris Design Archive` contributed to the system.

## Durable workflow

1. Start from the matured archive count and the current design-system Markdown. Verify the webapp manifest still matches the expected unique-reference count.
2. Compress the broad synthesis into a smaller set of execution clusters. For the current Hermes direction, the useful first compression is:
   - Soft Ambient Intelligence
   - Protected Luminous Container
   - Warm-Cool Human System Balance
   - Tactile Optical Material
   - Orbital Signal Rhythm
   - Quiet Editorial Archive
3. Make the `Chris Design Archive` section explanatory, not just a placeholder grid:
   - what the archive gave us: repeated signals and evidence
   - what was intentionally not copied: third-party names, slogans, logos, exact layouts, literal UI copy
   - how it becomes a system: `Reference → Evidence → Repeated Pattern → Compressed Cluster → Token / Component / Prompt Package / Critique Checklist`
4. Convert the clusters into a provider-independent prompt package. Include at least:
   - asset name/use case
   - positive prompt
   - negative prompt / guardrail
   - brand-safety caveat
5. Keep prompts portable across Higgsfield, Kling, OpenAI, Midjourney, etc. Do not embed provider-specific syntax unless Chris selected a provider.
6. Update both the canonical archive Markdown and the webapp public ASCII-safe copy. Preserve the Korean download filename when applicable.
7. Rework the `Design DNA` tab into three clear layers:
   - `About Design DNA`: compressed clusters + process
   - `Chris Design Archive`: what was learned from the archive and how evidence became the system
   - `Agentic Brand & Package System`: prompt package cards + guardrails + next production order
8. Verify locally and live with browser probes:
   - expected cluster count
   - expected prompt-card count
   - explanatory Chris Design Archive copy appears
   - no horizontal overflow on desktop/tablet/mobile
   - archive manifest count and doc popup/download still work

## Current prompt package shape

A practical first set of brand-asset prompts:

- Hermes App Icon / Presence Mark
- Ambient AI Dashboard Card
- OBD Context Signal Field
- Hermes Archive Cover
- Brand Package Label System

Each prompt must explicitly avoid copying any existing brand, text, logo, artwork, poster layout, app icon, campaign, or package label.

## Pitfalls

- Do not leave old placeholder copy such as “future archive” after real archive data exists.
- Do not dump the full Markdown into the Design DNA tab; the tab should be a skimmable operating surface, while the Markdown remains the canonical full document/download.
- Do not preserve unused React constants after replacing panels; TypeScript `noUnusedLocals` will fail the build.
- Do not verify only the Chris Archive tab. After changing Design DNA, probe all Design DNA subtabs plus the existing archive doc popup/download because shared data/doc paths can regress.

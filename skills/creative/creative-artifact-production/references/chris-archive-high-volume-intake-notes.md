- Use stable visual-DNA slugs based on the design pattern, not the Telegram/cache filename.

## Draft-update restraint

`DESIGN_SYSTEM_DRAFT.md` should accumulate tentative candidates, not final rules. When adding many entries, prefer:

- adding a new class-level heading only when a truly new reusable cluster appears;
- otherwise appending evidence/use cases to an existing class-level cluster;
- recording GoYJ review questions for shortlist/core-vs-support decisions;
- avoiding overgrown one-image-only headings when a broader cluster already exists.

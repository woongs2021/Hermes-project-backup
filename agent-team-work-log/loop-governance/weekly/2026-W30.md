1. **Visual credit/session risk**
   - 매일 3 still + videos/turntable까지 자동 확대하면 Higgsfield credit과 session 안정성 리스크가 커짐.
   - 권고: 기본은 still 3개까지만, video/turntable은 Chris approval 또는 홈페이지 최종 promotion 후보일 때만 생성.

2. **Visual metaphor convergence**
   - 최근 개선은 크지만 rounded container/storage/listening object 계열이 반복될 수 있음.
   - 권고: 다음 주에는 `threshold`, `instrument`, `surface`, `holder`, `signal marker`, `governance object` 등 family quota를 두고 같은 family 2일 연속 금지.

3. **SNS over-marketing risk**
   - Son loop가 subscriber tip을 포함하므로 성과 수치/전환 인과를 암시하기 쉬움.
   - 권고: 항상 “관찰할 신호”로만 표현하고 conversion lift 단정 금지.

4. **Faker scope creep**
   - August 후보가 많아졌음. 첫 coding week는 Data Inventory & Privacy Boundary와 HomeVisualHero/VisualDetailDisclosure 최소 계약으로 제한 필요.

5. **Privacy / trace exposure**
   - exact prompts, source paths, model metadata, 전달 status는 public UI에 노출하지 않아야 함. 비공개/관리자에서도 최소 공개 원칙 유지.

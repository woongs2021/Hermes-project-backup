## 4. 보류/조정해야 할 리스크

1. **Son generic marketing drift**
   - 현재 SNS 문안은 안전하지만 일반적인 AI/AX 조언에 가깝습니다.
   - 조정: 매 문안에 Chris님의 실제 운영 관찰을 공개 가능한 수준으로 1개 연결하되, 내부 에이전트명·파일 경로·비공개 프로젝트명은 노출하지 않습니다.

2. **AI/AX loop graph freshness gap**
   - 2026-08-14 Muyeol 검증에서 Faker 통합 탭/graph/consolidated-index 누락, graph-nodes/edges 장기 미갱신이 WATCH로 확인되었습니다.
   - 조정: SNS 사용자-facing 문안은 가능하지만, dashboard/graph 누적 자동화는 복구 전까지 검증 완료처럼 말하지 않습니다.

3. **Visual metaphor convergence**
   - 이번 주 후보는 capsule, block, cushion, wedge, canopy, arc 등으로 이름은 다양하지만 시각 문법은 `single rounded soft object` 중심입니다.
   - 조정: 다음 주는 family quota를 강제합니다. `document`, `architecture`, `instrument`, `signal marker`, `care object`, `governance artifact`, `surface/field` 중 같은 family는 7일 내 2회 초과 금지로 둡니다.

4. **Turntable credit/session risk**
   - Chris님 승인으로 daily 2+2는 진행 가능하지만, 매일 still 2개 + video 2개는 비용·세션 실패·재시도 비용이 큽니다.
   - 조정: 기본은 2 still + 2 turntable을 유지하되, 추가 revision은 Chris/Karina의 명시 피드백이 있을 때만 수행합니다. 자동 재시도는 후보당 1회까지로 제한합니다.

5. **Delivery packaging risk**
   - 2026-08-13에 산출물은 존재했으나 final response 첨부가 빠진 문제가 확인되었습니다.
   - 조정: generated-media loop는 `files_exist`, `metadata_saved`, `final_response_has_MEDIA`, `delivery_status_ok_or_autodelivery_confirmed` 네 가지를 모두 체크해야 합니다.

6. **Research overclaim risk**
   - W33 best-2 중 일부는 초록/메타데이터 또는 접근 제한 기반입니다.
   - 조정: Chris-facing 설명은 “프레임/렌즈/질문”으로 제한하고, 방법론·효과·일반화 주장은 전문 확인 전 금지합니다.

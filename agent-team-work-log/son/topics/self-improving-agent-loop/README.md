# Self-Improving Agent Loop 개념 노트

## 핵심 개념
- Chris님은 YouTube에서 찾은 캡쳐본을 바탕으로 `Self-Improving Agent Loop`를 생각하고 있다.
- 구조는 `데이터 → 에이전트 → 결과물 → 사람 피드백 → 피드백 주입 → 개선된 다음 루프`로 이해한다.
- 사람은 모든 실행을 직접 고치는 역할이 아니라, 결과물에 대해 좋고 나쁨을 판단하고 그 판단 기준을 구조화해 다음 루프에 반영시키는 역할이다.

## Chris님 관점과 연결
- 전일 답변의 역할 분담과 연결된다.
  - 에이전트: 데이터 수집, 루프 액션, 코딩 액션, 결과 생성, 유저 컨펌 요청
  - 사람: 루프 설계, 최종 품질 검증, 개선점 도출
- AI 신뢰는 단발성 자동 생성이 아니라 `실사용 마찰 발견 → 피드백/판단 → 수정·보완 → 다음 루프 개선`의 완성도에서 생긴다.

## PM/OBD 해석
- 이 개념의 제품 가치는 “사람이 모든 실행을 하지 않아도 된다”가 아니라, “사람의 판단 기준이 루프에 저장되어 실행 품질이 계속 올라간다”에 있다.
- 비즈니스/조직 설득 언어로는 `자동화된 업무 범위`, `효율화된 인력 업무`, `더 중요한 업무로의 인력 재배치`, `최종 품질 책임의 위치`를 함께 설명해야 한다.
- 단순한 good/bad 피드백만으로는 부족하므로, 향후에는 피드백 기준을 `정확성`, `목적 적합성`, `브랜드/톤`, `위험`, `실행성`, `수정 가능성` 등으로 구조화하는 방향이 필요하다.
